## 0. 何を測るか

0.7 秒の音声について、**2 つの時点**に印を付けます。

| | |
|---|---|
| `burst` | 閉鎖の解放（破裂）の瞬間 |
| `voicing_onset` | 声帯振動（周期性）が始まる瞬間 |

対象はすべて**発話の頭にある閉鎖音**です。したがってクリップの冒頭は
無音（または直前の非音声区間）で始まります。

**既存の値に合わせようとしないでください。** あなたの計測は、
他の測定値と**独立**であることに意味があります。

---

## 1. 意図的にお伝えしていないこと

次はすべて伏せてあります。**推測して計測を変えないでください。**

- 対象がどの種類の閉鎖音か
- 話者・語彙・転写
- 他の方法で測った値

クリップは**すべて 0.700 秒ちょうど**に揃えてあり、
対象のバーストが来る位置も**トークンごとにランダム**にしてあります。
長さや位置から答えを推測することはできません。

## 2. 作業の単位

作業は専用のウェブ画面で行う。1画面が1トークンで、
音声（0.700 秒・16 kHz・モノラル）と、その波形・スペクトログラムの図が出る。
`burst` と `voicing_onset` の2点を画面上で置く。判定不能の選択肢も画面にある。
ファイルの読み書きは不要で、Praat も使わない。

**対象は、クリップ内で最初に現れる閉鎖音の開放である。**
すべて発話頭の閉鎖音なので、クリップ冒頭は無音または直前の非音声区間で始まり、
**開始から 0.15〜0.25 秒のあいだに対象のバーストが来る**（位置はトークンごとに
ランダム化してある）。後続に別の閉鎖音が現れることがあるが、**最初のものだけ**を
計測する。

クリップは判断に必要な長さだけに絞ってある（前置き＋VOT＋有声の確認）。
不要に長くすると、対象でない閉鎖音を拾う危険と走査の手間が増えるためである。

---

## 3. 画面の表示について（設定は不要）

全員が同じ表示で作業する。設定を変える操作は無く、変える必要もない。

画面は上から3段になっている。

| 段 | 内容 |
|---|---|
| 上段 | 波形（全体スケール） |
| 中段 | 波形（高利得。弱いバーストを見つけるためのもので、母音部が振り切れるのは正常） |
| 下段 | スペクトログラム（0–8000 Hz、窓長 5 ms、ダイナミックレンジ 50 dB） |

**バーストは波形で、気音と有声開始はスペクトログラムで判断しやすい。**
必要に応じて拡大する。判断は最終的に 50–100 ms 幅まで拡大して行うのが望ましい
（最大まで拡大すると 1 ms が約40画素になる）。

数値（ミリ秒）は画面に出していない。判断が数値に引きずられないようにするためである。
精度は線の位置で担保される。

## 3.9 音声を聞くかどうか

**聞くことは必須ではない。判断に迷ったときに使ってください。**

理由は、この課題で音が効く場面と効かない場面がはっきり分かれるからである。

- **同定には効く** — 「いま見ているのが本当に対象の閉鎖音か」「解放が2回に
  分かれているのか、別の閉鎖音なのか」は、聞けば分かることがある
- **位置決めには効かない** — バーストも有声開始も、耳でミリ秒単位に
  決められる種類の境界ではない。**位置は波形とスペクトログラムで決める**

したがって「全件を必ず聞く」という規則にはしない。作業時間だけ増えて
測定の質は上がらない。**視覚的に曖昧なときに聞く**のが正しい使い方である。

**再生したかどうかは自動で記録される**（結果CSVの `plays` 列）。
計測者を評価するためではなく、**どの層でどれだけ音が要ったかを論文に
報告するため**である。気にせず、必要なときに必要なだけ再生してください。

## 4. ランドマークの定義

### 4.1 `burst`（VOT onset）

**閉鎖の解放にともなう最初の急峻なエネルギー上昇の時点。**

- 波形上で、無音（または閉鎖）から**振幅が不連続に立ち上がる最初の点**
- スペクトログラム上で、広帯域の縦縞（transient）が現れる時点
- **立ち上がりの開始点**に置く。ピークではない
- ゼロ交差に合わせる必要はない

### 4.2 `voicing_onset`（VOT offset）

**後続母音の周期的な声帯振動が始まる最初の時点。**

- 波形上で、**規則的な周期構造が始まる最初の周期の開始点**
- スペクトログラム上で、低域に声帯パルスの縦縞（voice bar / 基本周波数の
  ハーモニクス）が安定して現れ始める時点
- 気音（無声の乱流雑音）が周期性に置き換わる境界
- 最初の1周期は振幅が小さいことが多い。**周期性が識別できる最初の周期**を採る

### 4.3 `uncodable`（判定不能）

**判定できない場合は、無理に決めずに「判定不能」を選ぶ。**
`burst` と `voicing_onset` は未設定のままでよい。

判定不能は失敗ではない。**判定不能の分布そのものが本研究の分析対象である。**
迷った末に無理に線を置くより、判定不能に落とすほうが情報量が多い。

画面で理由を選ぶ。選択肢は次のとおり。

| ラベル | 意味 |
|---|---|
| `no_burst` | バーストが同定できない（完全に弱化、または雑音に埋もれる） |
| `no_voicing` | 後続の有声開始が同定できない（母音の無声化を含む） |
| `overlap` | 直前の音声（インタビュアーを含む）と重なって分離できない |
| `noise` | 雑音・クリッピング・録音不良で判断できない |
| `not_a_stop` | クリップ内に対象となる閉鎖音が見当たらない |
| `other` | 上記以外（自由記述を続けてよい） |

## 5. 判定困難な場合の扱い

### 5.1 バーストが2つ以上見えるとき

**まず二つの場合を区別する。**

**(a) 同じ閉鎖音の多重解放**
軟口蓋閉鎖音などで、解放の transient が2回以上に分かれて見えることがある。
間隔は概ね 10–30 ms で、あいだに母音は入らない。
→ **最初のバースト**を採る。ラベルに `multi` と記す。

**(b) クリップ内の別の閉鎖音**
語中に別の閉鎖音があり、そのバーストがクリップに入っている場合。
あいだに母音や共鳴音が入るので (a) とは見分けられる。

→ **対象は、ファイルに最初に現れるバースト**である。後続のバーストは無視する。

**なぜそう言い切れるか**: クリップは対象セグメントの開始より 150〜250 ms 前から
切り出してあり、対象は**発話頭**なので、通常その手前は無音である。
したがって最初に現れるバーストが対象になる。

**これは稀な状況ではない。** 本コーパスの対象トークンでは
**74.5% のクリップに別の閉鎖音のバーストが入る**（2つ目までの間隔は
中央値 198 ms、37.8% は 200 ms 以内）。**標準的な状況として扱うこと。**

**例外**: **1.3% のクリップは冒頭が無音でない**（直前の発話が入り込んでいる）。
その場合、先行部にバーストが含まれる可能性がある。
**対象がどれか特定できないときは `uncodable / other`** とし、理由を書く。


### 5.1.1 順序について

**見えたとおりに置く。** `voicing_onset` が `burst` より前になる場合もある（§5.2）。
画面では警告しない。

### 5.2 前有声化（prevoicing）— 声帯振動が解放より前に始まる場合

解放より前から低域の声帯振動が続いていることがある。

→ **`voicing_onset` は、声帯振動が実際に始まった時点**に置く。
　 結果として `burst` より前になり、VOT は負になる。**それでよい。**

**判断の分かれ目**は、声帯振動が閉鎖を通して**続いているか**である。

| 見え方 | 置き方 | VOT |
|---|---|---|
| 閉鎖を通して声帯振動が続き、そのまま母音へ | 振動の**開始点**に置く | 負 |
| 声帯振動がいったん止まり、解放後に再開する | **再開点**に置く | 正 |

迷う場合は `uncodable / other` とし、理由に「前有声化の判断がつかない」と書く。

### 5.3 気音が周期性へ滑らかに移行する

境界が段階的で一点に決めにくい場合がある。
→ **周期性が2周期連続で識別できる最初の周期の開始点**を採る。
それでも決められない場合のみ `uncodable / no_voicing`。

### 5.4 後続母音の無声化

高母音（/i/, /ɨ/, /u/）で母音が無声化していることがある。
→ 周期性が現れないので `uncodable / no_voicing`。
**気音の終端で代用しないこと。**

### 5.5 バーストが極めて弱い

→ 拡大して transient が識別できるなら計測する。
識別できないなら `uncodable / no_burst`。**「このあたりだろう」で置かない。**

### 5.6 インタビュアーの発話との重なり

このコーパスはインタビュアーが同一チャンネルに入っている（転写上は `<IVER>`）。
重なって分離できない場合は `uncodable / overlap`。

### 5.7 クリップ冒頭に対象がある／末尾で切れている

クリップは対象バーストの 0.15〜0.25 秒前から始まるので、通常は起こらない。
起きた場合は `uncodable / other` とし、理由を書く。

## 6. 作業の進め方

1. **画面に出る順に**進める。飛ばしても構わないが、順番を組み替えないこと
2. 1トークンにかける時間の目安は 30〜60 秒。迷ったら判定不能に落とす
3. **既存の境界を参照しない。** クリップには境界情報は入っていない
4. 途中で基準がぶれたと感じても、**戻って直さない**。そのまま進める
   （後から基準の変化を分析できるようにするため）
5. 中断してよい。入力は1件ごとに自動で保存され、別の日・別のパソコンで
   同じリンクを開けば続きから再開できる

同じトークンが複数の方に配られていることがある。計測者どうしのばらつきを
見積もるためで、**どれがそれかは伏せてある**。

---

## 7. 提出

入力は1件ごとに自動で送信される。**最後に何かを送る必要はない。**
全件が済むと画面に確認が出るので、そこで終了してよい。

作業中に気づいたこと（判断に迷った型、途中で基準が変わったと感じた箇所など）が
あれば、メールでお知らせいただけると助かる。
