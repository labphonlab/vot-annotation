# VOTの手計測（参照値の作成） 手続き書

**版: 1.1（2026-08-15）**
対象: `data/derived/annotation_sample/A/`（1,800トークン）
二重計測: `data/derived/annotation_sample/B/`（324トークン、A と同一音声）

---

## 0. この作業が何のためのものか

Seoul Corpus の音素境界は、音素同定については高い一致率が報告されている
（98.1%、N=5,152、9名の全ペア照合）が、**バースト開始と有声開始という
VOTランドマークの妥当性は保証されていない**。配布マニュアルにも
セグメンテーション基準の規定がない（基準書1,141枚と動画は配布物に非同梱）。

そこで**独立した参照値**を作り、既存のセグメント境界および自動測定
（Dr.VOT）と突き合わせる。

**重要**: あなたの計測値は「正解」として使われるのではなく、
**既存の測定値と比較される独立の測定**として使われる。
既存の境界に合わせようとしないこと。

---

## 1. 計測者に与えられない情報（意図的）

次はすべて意図的に伏せてある。**推測して計測を変えないこと。**

- 対象が平音か激音か（硬音は含まれない）
- 話者ID・年齢・性別
- 語彙・転写・語彙頻度
- 既存のセグメント境界、自動測定値
- そのトークンが二重計測の対象か否か

クリップは**全て 0.700 秒ちょうど**に揃えてある。長さから持続時間を
推測することはできない（意図的にそう設計している）。

**計測者2（著者でないほう）には、本研究の研究課題・仮説・予測を伝えない。**
本書だけを渡す。これは意図的な設計である。計測者1（著者）は仮説を知っているため、
両者の `uncodable` 率や判断の傾向を比較することで、
**仮説を知っていることによるバイアスが生じたかを事後に検定できる**。
2人目に予測を伝えると、この診断が使えなくなる。

## 2. 作業の単位

各トークンにつき次の2ファイルが対になっている。

```
T00001.wav        0.700 秒、22.05 kHz、モノラル、16 bit
T00001.TextGrid   空のポイント層3本（burst / voicing_onset / uncodable）
```

**対象は、クリップ内で最初に現れる閉鎖音の開放である。**
すべて発話頭の閉鎖音なので、クリップ冒頭は無音または直前の非音声区間で始まり、
**開始から 0.15〜0.25 秒のあいだに対象のバーストが来る**（位置はトークンごとに
ランダム化してある）。後続に別の閉鎖音が現れることがあるが、**最初のものだけ**を
計測する。

クリップは判断に必要な長さだけに絞ってある（前置き＋VOT＋有声の確認）。
不要に長くすると、対象でない閉鎖音を拾う危険と走査の手間が増えるためである。

## 3. Praat の表示設定（統一する）

全員が同じ設定で作業する。異なる設定は境界判断を変える。

```
Spectrogram settings...
    View range (Hz):        0 – 11000     ← 22.05 kHz なので上限は 11 kHz
    Window length (s):      0.005         ← 広帯域。バーストの時間分解能を優先
    Dynamic range (dB):     50
    Window shape:           Gaussian

Pitch settings...
    Pitch range (Hz):       75 – 500      （有声開始の確認補助。必須ではない）

Advanced spectrogram settings...
    Number of time steps:   1000
    Number of frequency steps: 250
```

**波形とスペクトログラムを必ず両方表示する。** バーストは波形で、
気音と有声開始はスペクトログラムで判断しやすい。
必要に応じて拡大するが、**判断は最終的に 50–100 ms 幅で拡大して行う**。

> **注記**: 配布音声は 22.05 kHz である（コーパスマニュアルと原典論文はいずれも
> 44 kHz と記載しているが、配布物は 22.05 kHz）。したがってスペクトログラムの
> 上限は 11 kHz であり、**歯茎・軟口蓋バーストの高域成分の一部は見えない**。
> この制約は全トークンに等しくかかる。

## 3.9 音声を聞くかどうか

**聞くことは必須ではない。判断に迷ったときに使ってください。**

理由は、この課題で音が効く場面と効かない場面がはっきり分かれるからである。

- **同定には効く** — 「いま見ているのが本当に対象の閉鎖音か」「解放が2回に
  分かれているのか、別の閉鎖音なのか」は、聞けば分かることがある
- **位置決めには効かない** — バーストも有声開始も、耳でミリ秒単位に
  決められる種類の境界ではない。**位置は波形とスペクトログラムで決める**

したがって「全件を必ず聞く」という規則にはしない。作業時間だけ増えて
測定の質は上がらない。**視覚的に曖昧なときに聞く**のが正しい使い方である。

**再生したかどうかは自動で記録される**（結果CSVの `plays` 列）。
計測者を評価するためではなく、**どの層でどれだけ音が要ったかを論文に
報告するため**である。気にせず、必要なときに必要なだけ再生してください。

## 4. ランドマークの定義

### 4.1 `burst`（VOT onset）

**閉鎖の解放にともなう最初の急峻なエネルギー上昇の時点。**

- 波形上で、無音（または閉鎖）から**振幅が不連続に立ち上がる最初の点**
- スペクトログラム上で、広帯域の縦縞（transient）が現れる時点
- **立ち上がりの開始点**に置く。ピークではない
- ゼロ交差に合わせる必要はない

### 4.2 `voicing_onset`（VOT offset）

**後続母音の周期的な声帯振動が始まる最初の時点。**

- 波形上で、**規則的な周期構造が始まる最初の周期の開始点**
- スペクトログラム上で、低域に声帯パルスの縦縞（voice bar / 基本周波数の
  ハーモニクス）が安定して現れ始める時点
- 気音（無声の乱流雑音）が周期性に置き換わる境界
- 最初の1周期は振幅が小さいことが多い。**周期性が識別できる最初の周期**を採る

### 4.3 `uncodable`（判定不能）

**判定できない場合は、無理に決めずにここに点を打つ。**
`burst` と `voicing_onset` は空のままにする。

判定不能は失敗ではない。**判定不能の分布そのものが本研究の分析対象である。**
迷った末に無理に点を打つより、`uncodable` に落とすほうが情報量が多い。

`uncodable` の点にラベルを付けて理由を記録する。ラベルは次の語のいずれか。

| ラベル | 意味 |
|---|---|
| `no_burst` | バーストが同定できない（完全に弱化、または雑音に埋もれる） |
| `no_voicing` | 後続の有声開始が同定できない（母音の無声化を含む） |
| `overlap` | 直前の音声（インタビュアーを含む）と重なって分離できない |
| `noise` | 雑音・クリッピング・録音不良で判断できない |
| `not_a_stop` | クリップ内に対象となる閉鎖音が見当たらない |
| `other` | 上記以外（自由記述を続けてよい） |

## 5. 判定困難な場合の扱い

### 5.1 バーストが2つ以上見えるとき

**まず二つの場合を区別する。**

**(a) 同じ閉鎖音の多重解放**
軟口蓋閉鎖音などで、解放の transient が2回以上に分かれて見えることがある。
間隔は概ね 10–30 ms で、あいだに母音は入らない。
→ **最初のバースト**を採る。ラベルに `multi` と記す。

**(b) クリップ内の別の閉鎖音**
語中に別の閉鎖音があり、そのバーストがクリップに入っている場合。
あいだに母音や共鳴音が入るので (a) とは見分けられる。

→ **対象は常に最初のバースト**である。後続のバーストは無視する。

**なぜそう言い切れるか**: クリップは対象セグメントの開始 100 ms 前から
切り出してあり、対象は**発話頭**なので直前は無音である。
したがって**冒頭の無音の直後に来るバーストが対象**であり、それより後のものは
すべて対象ではない。判断に迷ったら、時間で選ぶのではなく
**冒頭の無音がどこで終わるか**を見ること。

**これは稀な状況ではない。** 本コーパスの対象トークンでは
**74.5% のクリップに別の閉鎖音のバーストが入る**（2つ目までの間隔は
中央値 198 ms、37.8% は 200 ms 以内に来る）。**標準的な状況として扱うこと。**

なお、冒頭が無音でないクリップが 1.3% ある（先行発話が入り込んだもの）。
その場合に対象が特定できなければ `uncodable / other` とし、理由を書く。

### 5.1.1 順序について

**`voicing_onset` は必ず `burst` より後**に来る。前有声化があっても同じである
（§5.2）。逆転している場合は置き間違いなので、画面に警告が出る。
警告が出ているあいだ、そのトークンは記入済みとして数えない。

### 5.2 前有声化（prevoicing）

バースト前に低域の声帯振動が見えることがある。
→ **`burst` はあくまで解放の時点**に置く。前有声化があっても
`voicing_onset` は**解放後の**周期性開始に置く。ラベルに `prevoiced` と記す。

### 5.3 気音が周期性へ滑らかに移行する

境界が段階的で一点に決めにくい場合がある。
→ **周期性が2周期連続で識別できる最初の周期の開始点**を採る。
それでも決められない場合のみ `uncodable / no_voicing`。

### 5.4 後続母音の無声化

高母音（/i/, /ɨ/, /u/）で母音が無声化していることがある。
→ 周期性が現れないので `uncodable / no_voicing`。
**気音の終端で代用しないこと。**

### 5.5 バーストが極めて弱い

平音でしばしば起こる。
→ 拡大して transient が識別できるなら計測する。
識別できないなら `uncodable / no_burst`。**「このあたりだろう」で置かない。**

### 5.6 インタビュアーの発話との重なり

このコーパスはインタビュアーが同一チャンネルに入っている（転写上は `<IVER>`）。
重なって分離できない場合は `uncodable / overlap`。

### 5.7 クリップ冒頭に対象がある／末尾で切れている

クリップは対象バーストの 0.15〜0.25 秒前から始まるので、通常は起こらない。
起きた場合は `uncodable / other` とし、理由を書く。

## 6. 作業の進め方

1. `A/` の中を **token_id の順に**進める。順番を変えないこと
2. 1トークンにかける時間の目安は 30〜60 秒。迷ったら `uncodable` に落とす
3. TextGrid は**上書き保存**する（`Save as short text file...`、同じファイル名）
4. **既存の境界を参照しない。** クリップには境界情報は入っていない
5. 途中で基準がぶれたと感じたら、**戻って直さず**、その旨を記録して申告する
   （後から基準の変更点を分析できるようにするため）

### 二重計測

`B/` は `A/` と同一の音声である。**2人目の計測者が、1人目の結果を見ずに**
独立に計測する。1人目が `A/` を、2人目が `B/` を担当する。
`B/` の内容が `A/` の部分集合であることは、2人目に伝えてよい
（どのトークンが対象かは、判断に影響しないため）。

---

## 7. 提出

- `A/` および `B/` の TextGrid をそのまま返す（wav は返さなくてよい）
- 作業ログ（開始日・終了日・所要時間・基準がぶれた箇所の申告）を添える

集計は `scripts/annotation/` の集計スクリプトが行う。
一致指標は `docs/annotation_agreement.md` に全報告する
（平均誤差・中央値誤差・MAE・Bland–Altman の95% agreement limits・
5ms/10ms以内一致率・喉頭クラス別／調音位置別／話者別の誤差・
回帰の切片と傾き・ICC）。**ICC 単独では判定しない。**

## 8. この手続き書自体について

Seoul Corpus のセグメンテーション基準が非公開であるため、本研究は
**自前の基準を明文化して公開する**。本書はその公開物である。
改訂した場合は版番号を上げ、どのトークンがどの版で計測されたかを記録する。
